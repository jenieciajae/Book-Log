# Jeniecia's Book Log 

🌐 **Live Demo:** https://jeniecia-book-log.web.app

A responsive book tracking app built with HTML, CSS, JavaScript, and Firebase.

## Features

- Search for books using the Google Books API
- Add books to a personal library
- Organize books by reading status:
  - Currently Reading
  - Want to Read
  - Finished Reading
- Track reading statistics and average ratings
- Write and share community reviews
- Edit and delete saved books and reviews
- Custom toast notifications for user feedback
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Books API
- Local Storage
- jQuery / jQuery UI

## Design

The design focuses on creating a cozy and personalized reading experience inspired by modern book tracking applications.

Features include:
- Soft pastel color palette
- Responsive layouts
- Interactive book cards
- Custom UI components
- Mobile-friendly navigation
